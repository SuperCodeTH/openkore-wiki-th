items_control.txt

กำหนดว่าไอเทมใดควรเก็บไว้ ฝากคลัง หรือขาย

รูปแบบบรรทัด

ชื่อไอเทม  จำนวนขั้นต่ำที่เก็บไว้  ฝากคลัง  ขาย  ใส่รถเข็น  เอาจากรถเข็น

ตัวอย่าง

Jellopy      0   1   0
Red Potion   20  1   0
Fly Wing     30  0   0
Knife        0   0   1
Flower       0   0   0   1
  • Jellopy ฝากเข้าคลังทั้งหมด
  • Red Potion เก็บไว้ 20 ขวด และฝากส่วนเกิน
  • Fly Wing เก็บไว้ทั้งหมด
  • Knife ขายทั้งหมด เว้นแต่อาวุธกำลังสวมใส่

ฝากของทุกอย่าง

all 0 1 0

ใช้เป็นค่าเริ่มต้นสำหรับไอเทมที่ไม่ได้ระบุเป็นรายรายการ ต้องเปิด storageAuto ใน config.txt ด้วย

ข้อควรระวัง

  • ไอเทมที่กำลังสวมใส่จะไม่ถูกขายหรือฝากคลัง
  • ชื่อไอเทมต้องตรงกับที่ OpenKore แสดง
  • ทดสอบด้วยไอเทมที่ไม่สำคัญก่อน
