ฝากของเข้าคลังอัตโนมัติ

ตั้งค่าร่วมกันระหว่าง config.txt และ items_control.txt

ตัวอย่าง NPC มาตรฐาน

storageAuto 1
storageAuto_npc prontera 150 187
storageAuto_distance 5
storageAuto_npc_type 1
storageAuto_npc_steps
itemsMaxWeight_sellOrStore 70
minStorageZeny 50

เปลี่ยน prontera 150 187 เป็นแผนที่และพิกัด NPC คลังจริงของเซิร์ฟเวอร์

NPC แบบกำหนดเอง

storageAuto_npc_type 3
storageAuto_npc_steps c r1 c r0 n

ลำดับเมนูต้องตรวจจาก NPC ของเซิร์ฟเวอร์นั้น ไม่ควรคัดลอกตัวอย่างโดยไม่ทดสอบ

ถ้าไม่ทำงาน

  1. ตรวจว่า storageAuto 1
  2. ตรวจแผนที่และพิกัด NPC
  3. ตรวจ items_control.txt ว่ามี all 0 1 0 หรือรายการที่ตั้งฝากคลังเป็น 1
  4. ตรวจว่ามี Zeny ตามค่า minStorageZeny
  5. ถ้าเลือกเมนูผิด ให้ใช้ชนิด 3 และบันทึกลำดับเมนูใหม่
