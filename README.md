# OpenKore Wiki ภาษาไทย

ชุดเอกสารภาษาไทยรูปแบบ MediaWiki สำหรับนำไปสร้างหรืออัปโหลดบน OpenKore Wiki

## สถานะ

ชุดเริ่มต้นนี้ประกอบด้วยหน้าหลัก สารบัญ การติดตั้ง และการตั้งค่าฝากคลัง โดยจะเพิ่มหน้าอื่นเป็นชุดต่อไป

## วิธีใช้งาน

1. เปิดไฟล์ `.wiki` ด้วยโปรแกรมแก้ไขข้อความที่รองรับ UTF-8
2. สร้างหน้าตามชื่อไฟล์บน Wiki
3. คัดลอกเนื้อหาทั้งหมดไปวางในช่องแก้ไข
4. ตรวจลิงก์และตัวอย่างให้ตรงกับเวอร์ชัน OpenKore และเซิร์ฟเวอร์ของคุณก่อนบันทึก

โค้ดและชื่อคีย์ของ OpenKore จะคงเป็นภาษาอังกฤษเพื่อให้คัดลอกไปใช้งานได้โดยตรง
