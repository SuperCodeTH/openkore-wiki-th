OpenKore Wiki ภาษาไทย

คู่มือภาษาไทยสำหรับการติดตั้งและตั้งค่า OpenKore

เอกสารนี้เป็นชุมชนจัดทำ ค่าบางอย่างอาจแตกต่างตามเซิร์ฟเวอร์และเวอร์ชันของ OpenKore

เริ่มต้นใช้งาน

ติดตั้งและเริ่มใช้งานเตรียมไฟล์และทดสอบ OpenKore ตั้งค่า config.txtคีย์หลักที่ใช้ควบคุมบอท Config Referenceรายการคีย์ config ครบ 605 รายการ จัดการไอเทมกำหนดเก็บ ฝากคลัง หรือขาย ฝากคลังอัตโนมัติตั้งค่า NPC และเงื่อนไขฝากของ

โครงสร้างเอกสาร

  • พื้นฐานและการติดตั้ง
  • ไฟล์ตั้งค่าหลัก
  • Config Reference คีย์ทั้งหมด
  • ไฟล์ควบคุมไอเทม
  • ระบบฝากคลังอัตโนมัติ
